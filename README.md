# 📦 OptiFlow // Neural Inventory Engine

**OptiFlow** is a high-performance, full-stack inventory management system. It features a futuristic, dark-themed interface with real-time data handling, secure user authentication, and predictive stock analytics.

---

## 🚀 Key Features
* **Secure Auth:** JWT-based login system with protected API routes.
* **Dynamic Dashboard:** Real-time stock monitoring with "Critical Level" alerts.
* **Advanced CRUD:** Full ability to Register, Modify, and De-register assets.
* **Smart Search:** Instant asset filtering by name or SKU.
* **High-End UI:** Glassmorphism design with custom CSS-keyframe animations.

## 🛠️ Tech Stack
* **Frontend:** React.js, Vite, Axios, React-Router-Dom
* **Backend:** Node.js, Express.js
* **Database:** MySQL (Relational Schema)
* **Styling:** Ultra-Modern Dark Theme (CSS-in-JS)

## 🔧 Installation & Setup
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/OptiFlow.git`
2. Install dependencies for both folders:
   - `cd server && npm install`
   - `cd client && npm install`
3. Set up your MySQL database using the provided schema.
4. Run `npm run dev` in both folders.
